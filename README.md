#Portfolio Project# 

## Purpose of Portfolio
The purpose of this portfolio is to incorporate learnings from the course into a functional deloyed website.
This portfolio website is to contain a home page for the user to return to as well as enabling the user to navigate to different sections using the navigation bar. 
This portfolio will include information for the user to get to know about the author, myself. 
The website will be compatible with mobile devices and tablets with an user friendly user interface in addition to desktops and laptops.

### Features

#### Color combination & Layout

The webiste is a reflection of my personality.
The aim was to have a clear and easy to use website whilst adding some additional features. 
The color combination was determined using [Color Palettes for Design](https://colorhunt.co/)

## Icons
The icons I selected were mostly deco or line style to keep the website style simple and clean. Accessed and downloand from icon8.com

### Navigation
-About 
The page provides a short information to my professional background and my hobbies. A work history button is available on the page to enable the user to navigate to detailed work history information, and another button to download a dummy cv.

-Projects 
The page showcases dummy past projects. 

- Get in Touch with me page.
This page will allow the user to connect with me using the contact form. The user will be asked enter their name and email address with a short message.
